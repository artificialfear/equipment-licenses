# Raven Band Equipment Licenses

Students study care rules and pass a test to earn a license for each area of the band room:

- **L-00 Band Room Basics** (required first)
- **P-01 Sticks, Mallets & Auxiliary**
- **P-02 Drums**
- **P-03 Keyboard Percussion**
- **P-04 Timpani**
- **W-01 School-Owned Winds**

Passing = 80% overall **and** every critical question correct. A pass produces a certificate with a verification code; the director's tab checks codes. A license is active only after the director initials the hands-on check-off.

Question content is encoded in `index.html` so the answer key isn't readable in View Source. Edit the readable source and re-encode rather than editing this file by hand.
